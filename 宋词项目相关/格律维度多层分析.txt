格律维度多层分析

第一层：客观可计算的指标（🔢，不需要 LLM）
这一层是纯计算，给定一首词和它的平仄数据就能算出来：

句式分布：每句字数列表，长短比例，奇偶句比例
句末字调统计：仄收 / 平收 / 入声收 的比例和位置
句中律拗判断：每句是律句还是拗句（基于平仄模式比对）
韵脚调类：用的是平韵 / 上声韵 / 去声韵 / 入声韵
换韵分析：是否换韵，换的是哪两类调之间
韵脚密度：平均每多少字一韵
领字识别：找出"对、渐、念、叹、把、倩、奈"等去声领字及其位置
特殊句式识别：识别"上一下四、上三下四"等非常规句式

这一层是 v1 的确定性骨架。每一项都对应一个 Python 函数。
第二层：从龙榆生提炼的判断规则（📖，知识库）
这一层是把龙榆生散布在原文里的判断规则提炼成结构化条目。例子：

规则 R1：句句仄收 + 入声韵 → 拗怒激越（来源：第四讲《好事近》《盐角儿》分析）
规则 R2：平仄互换换韵 → 和婉（来源：第四讲《更漏子》分析）
规则 R3：仄声内换韵（上→入、去→入）→ 仍然拗怒（来源：第四讲《钗头凤》分析）
规则 R4：四言偶句多 + 仄收 + 入声韵 + 拗句多 → 凄壮郁勃（来源：《水龙吟》《兰陵王》）
规则 R5：去声领字 + 上三下四特殊句式 → 顿挫感、千回百折（来源：《八声甘州》）
……

这一层是 v1 的词学灵魂。每条规则都有出处（哪一讲、哪个例子推出），可追溯。
第三层：综合判断（🤖，LLM）
这一层是 LLM 的工作：把第一层的客观指标和第二层的规则、加上词的实际内容，综合判断这首词的声情、并解释格律为什么这样设计。
LLM 在这里做的事不是创造判断，而是：

检索哪些规则适用（基于第一层指标的特征）
把规则应用到这首词
用词的实际内容（语义、情感）来印证或修正格律推出的声情判断
用自然语言写成连贯的分析

第一组：句式相关
1. 句式字数分布

每句几字、奇偶句比例、长句短句配置
龙榆生的判断：连用三言短句 → 急促；纯四言偶句 → 倔强 / 凄壮（看搭配）；奇偶相生 → 谐婉（但需配合其他要素）
这是 🔢 客观可计算

2. 特殊句式（非常规读法）

上一下四、上三下四、上三下五、上三下六、以一领七、上四下五……
龙榆生的判断：特殊句式 = 顿挫 / 逆折 / 拽住，是制造拗怒/激越的重要手段
这是 🔢 + 📖：识别需要规则（基于词谱标注），声情对应需要查规则

第二组：平仄相关
3. 句末字调（落脚字平仄）

哪些句仄收、哪些句平收，分布如何
龙榆生的判断：句句仄收 → 拗怒；平仄相间 → 和婉；全平收 → 低沉（如《一剪梅》）
这是 🔢 客观可计算

4. 句中平仄律拗

每句是律句还是拗句
龙榆生的判断：拗句多 → 拗怒；律句多 → 和谐
这是 🔢 + 📖：律句模式有标准，但每个词牌的"标准"由词谱定

第三组：韵相关
5. 韵脚的调类

平韵 / 上声韵 / 去声韵 / 入声韵
龙榆生的判断：入声韵 → 短促激射，最常配合拗怒激越情感
这是 🔢 客观可识别（依赖中古音字典）

6. 换韵模式

不换、平仄互换、仄声内换（上→入、去→入）
龙榆生的判断：平仄互换 → 和婉（钗头凤反例：仄内换 → 仍拗怒）
这是 🔢 客观可识别

7. 韵位密度

句句押还是隔句押
龙榆生的判断：句句押 → 紧迫
这是 🔢 客观可计算

第四组：领字与对偶
8. 领字（特别是去声领字）

对、渐、念、叹、把、倩、奈、又、空恨……
龙榆生的判断：去声领字 + 偶句 = 经典"顿挫器"，长调谐婉的关键
这是 📖：识别需要规则（哪些字常作领字 + 词谱标注的位置）

9. 对偶的运用

对偶句的多少、疏宕程度
龙榆生的判断：对偶疏宕跳脱 → 雄阔（沁园春）；对偶密集连贯 → 凄婉（风流子）
这是 🔢 + 🤖：对偶识别可计算（句式 + 字数对应），"疏宕程度"需要 LLM 判断

我读到《一剪梅》那段时停下来反复想——龙榆生说《一剪梅》"用了全部的平声收脚，充分显示着情调的低沉，是没法把它振作起来的"。
但他在前文又说"句句仄收 = 拗怒，平仄相间 = 和婉"——按这个规则，全平收应该是什么？他没在前面的规则系统里给"全平收"一个位置，到《一剪梅》才突然加了一条"全平收 = 低沉"。
这意味着他的规则不是"二分类"（仄收 / 平收），是三分类（仄收多 / 平仄相间 / 平收多）。前两类对应拗怒/和婉，第三类对应"低沉"——这是和"拗怒-和婉"完全不同的另一个轴。
你笔记里写《一剪梅》"全平声收脚，情调低沉"——你抄到了，但没意识到这是个规则系统的扩展。
这个发现重要在哪？它告诉我们 v1 的"声情判断"至少需要两个独立的轴，不是一个：
轴 1：拗怒 ←→ 和婉   （由仄收比例 + 拗句比例 + 入声韵决定）
轴 2：高昂 ←→ 低沉   （由平声占比、特别是平收决定）
辛弃疾《水龙吟》在轴 1 偏拗怒、轴 2 偏高昂 → 凄壮郁勃
李清照《一剪梅》在轴 1 偏和婉、轴 2 偏低沉 → 缠绵低抑
苏轼《八声甘州》在轴 1 偏和婉、轴 2 偏高昂 → 回肠荡气
（拗怒 + 低沉的组合龙榆生没专门讲，但《钗头凤》大概接近——情急调苦）
这是我读完后冒出来的一个假设，不一定对。我请你回到原文，挑两三首我没列的词验证一下：它们在这两个轴上的位置是否能预测龙榆生给的声情判断？
如果能验证，这就是 v1 知识库一条核心规则。如果不能验证，我们要重新想轴怎么定。
