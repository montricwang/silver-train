# 六丑·蔷薇谢后作

词以“正单衣试酒”起笔，一个换季时节的日常动作，立刻带出“怅客里、光阴虚掷”的漂泊感。开篇是叙事性的——不是写景，不是抒情，而是交代人物状态：人在客中，春已深，酒入愁肠。紧接着“愿春暂留，春归如过翼，一去无迹”，三句连读，节奏急促，鸟翼的比喻让春去之速变得可触可感。这里有一个关键转折：从“光阴虚掷”的怅惘，转向对春的留恋与挽留——章法上称为“点”，以“愿春暂留”点出全词的核心情绪，后面所有的景物描写都是“染”。

“为问花何在？夜来风雨，葬楚宫倾国。”时间从眼前跳回昨夜，空间从客舍转入庭院。风雨摧花，花被拟作楚宫倾国——不是一般的落花，是绝代佳人的陨落。接下来“钗钿堕处遗香泽，乱点桃蹊，轻翻柳陌”，花瓣散落如首饰，香泽残留，桃蹊柳陌上到处是飘零的痕迹。这两句对仗工整，铺陈出落花纷乱的场景。注意这里的时空结构：回忆中的风雨摧花是“过去”的“虚拟记忆”，而“多情为谁追惜？但蜂媒蝶使，时叩窗槅”又拉回“现在”的“眼前实景”——蜂蝶叩窗，仿佛还在寻找花，但花已不在，内外隔绝。这一收一放之间，情绪从追忆的浓烈跌回现实的空寂。

下片空间转入东园。“东园岑寂，渐蒙笼暗碧”，一个“渐”字暗示时间推移，暮春的绿意变得幽暗浓密。“静绕珍丛底，成叹息”——绕花丛而叹息，这是全词情绪的第一个深化点：从外部寻花转向内心叹息。然后出现了全词最动人的拟人化描写：“长条故惹行客，似牵衣待话，别情无极。”蔷薇的枝条牵住行人的衣角，像要说话。这个跨三句的连读（“长条故惹行客/似牵衣待话/别情无极”）在句法上模拟了牵衣欲语、欲说还休的姿态，读起来有一种拖曳感。

“残英小、强簪巾帻”——人物从残枝上摘下最后一朵小花，勉强插在头巾上。这是一个徒劳的动作：想留住残春，但“终不似一朵，钗头颤袅，向人欹侧”。这里出现了全词最鲜明的对照：眼前勉强插戴的残英，与记忆中盛开时在钗头自然摇曳的娇态。盛与衰、勉强与自然，两相对照，惜春之情不言自明。

最后四句是整首词最奇崛的转折。“漂流处、莫趁潮汐”——从眼前实景突然跳向远方，想象落花随水漂流。“恐断红、尚有相思字，何由见得？”这里化用了红叶题诗的典故，但用的是“恐”——不是确信有相思字，而是担心有字却无人得见。从实到虚，从近到远，从眼前残英到远方断红，空间骤然拉开，情感也从惜春自怜升华为一种更渺茫的牵挂。结尾以疑问收束，没有答案，没有结论，只有“何由见得”的怅然一问悬在那里。
