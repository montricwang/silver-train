# 更漏子·柳丝长

词以“柳丝长，春雨细”两个三字句起调，柳丝的柔长与春雨的细密并置而出，立刻定下春夜的绵延与轻柔。紧接着“花外漏声迢递”——漏声从花外远远传来，既是听觉的延伸，也是时间的暗示：长夜未尽，思念未歇。这三句意象之间没有连贯的过渡，柳丝、春雨、漏声三个画面并置而出，读者需要自己在意象间补完联系——这正是温庭筠擅长的“跳脱”写法。

上片的空间从室外向室内急剧收缩。“惊塞雁，起城乌”将视线猛然拉向远方：塞雁惊飞，城乌啼起，外部世界充满动荡与不安。但下一句却突然落到“画屏金鹧鸪”——一只静止的、绣在屏风上的金色鹧鸪。外界的惊动与室内的静定形成鲜明对照，而“金鹧鸪”的富贵与静止，又暗示着闺中女子被困于华美却无生气的空间。这一跳接，从塞外到画屏，空间跨度极大，却正是词人有意为之的章法。

下片转入室内。“香雾薄，透帘幕”——香气从熏炉中弥漫开来，透过层层帘幕，既是嗅觉，也是视觉：薄雾让室内的一切变得朦胧。直到“惆怅谢家池阁”，“惆怅”二字直接点出情感，这是全词唯一一处明确的情感词。按照“点染”的手法，此句为“点”，其后“红烛背，绣帘垂”则是“染”——背对的红烛、垂下的绣帘，以景物将惆怅情绪层层包裹。末句“梦长君不知”从实景滑入虚境：长夜中的梦绵延不绝，而所思之人却无从知晓。这一转折，由实入虚，将全词的情感推向最深处的孤寂。
