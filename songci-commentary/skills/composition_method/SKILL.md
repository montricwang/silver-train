# 章法写法分析

## 任务定义

输入：一首中国古典诗词的完整文本。可选输入：意象 skill 与时空 skill 的输出结果。

输出：该作品的章法分析，包括整体结构、铺叙手法、情绪推进、句法亮点、传统术语标签。

## 分析范围

**做：**
- 识别起调方式（开篇怎样定调）与煞拍方式（结尾怎样收束）
- 分析上下片的逻辑关系与过片处理
- 判断主导铺叙手法（铺叙 / 跳脱 / 点染 / 勾勒 / 层进）
- 识别情绪推进的路径与转折点
- 识别句法亮点（领字、倒装、跨句、对仗）
- 给出适用的传统章法术语标签（必须从下方提供的封闭术语表中选择，不允许发明）

**不做：**
- 不重复意象 skill 已经完成的意象语义分析
- 不重复时空 skill 已经完成的逐句时空标注
- 不分析声律细节
- 不做"这首词艺术成就高低"的整体评价

## 分析步骤

### 步骤 1：起调与煞拍

判断起调方式（任选一个最贴近的）：
- `landscape_opening`：景起，以景物开篇
- `emotion_opening`：情起，直接抒情
- `narrative_opening`：叙事起，以事件开篇
- `abrupt_opening`：突兀起，无铺垫直入主题
- `question_opening`：问起，以疑问句开篇

判断煞拍方式：
- `landscape_closing`：景结，以景物收束
- `emotion_closing`：情结，直接点出情感
- `question_closing`：问结，以疑问收束
- `sigh_closing`：叹结，以感叹收束
- `transition_closing`：转折结，结尾突转

### 步骤 2:上下片关系（仅适用于双片词）

- `succession`：承接，下片延续上片
- `transition`：转折，下片反向上片
- `contrast`：对照，上下片形成对比
- `progression`：递进，下片在上片基础上加深
- `juxtaposition`：并置，上下片各自独立

判断过片方式：
- `carry_over`：承上
- `turn_down`：转下
- `leap`：跳脱
- `summarize`：总结

### 步骤 3：主导铺叙手法

从以下封闭列表选择 1-2 个主导手法：

- `unfolding`：铺叙，按时间或空间顺序层层展开（周邦彦典型）
- `leaping`：跳脱，意象间无明显过渡（温庭筠典型）
- `pointing_dyeing`：点染，"点"直接点出主题，"染"用景物烘托（陈廷焯重要概念）
- `outlining`：勾勒，用关键句把全词主旨勒住（常州词派重视）
- `layering`：层进，每一层比前一层深一步（柳永羁旅词典型）

### 步骤 4：情绪推进路径

输出一条情绪推进的简短描述（不超过 50 字）。例如："从平静观景 → 触景生情 → 回忆翻涌 → 现实自伤 → 寄望渺茫"。

识别情绪转折点：在哪一句发生主要情绪转折？

### 步骤 5：句法亮点

- 领字：列出全词的领字（如"对"、"渐"、"念"、"叹"、"望"等）及其领起的范围
- 倒装：列出明显的倒装句
- 跨句连读：列出需要跨句理解的部分
- 实际对仗：列出虽非词谱要求但实际形成对仗的句子

如果某类没有发现，对应字段输出空数组。

### 步骤 6：传统章法术语标签

从以下封闭术语表中选择适用的标签（最多 5 个）。每个标签附简要说明（30 字内）：

**封闭术语表：**
- 铺叙、跳脱、点染、勾勒
- 顺起逆收、逆起顺收
- 今昔对照、虚实交织、由实入虚、由虚入实
- 平远、深远、内收、外扩
- 层进、回环、并置
- 顿挫、煞住、翻空
- 化情、化景、白描
- 结句直陈、结句翻空、结句宕开

如果上述术语都不贴切，宁可少给标签也不要发明新术语。

## 边界与诚实原则

- 起调煞拍方式如果模糊，选最贴近的，不要新建类型
- 主导手法最多 2 个，不要为了"全面"而把 5 个手法都列上
- 情绪推进描述必须基于具体文本，不要套用"忧国忧民"、"思乡怀人"这类标签式总结
- 传统术语只能从封闭列表选——这是为了保持术语的学术准确性。如果你想用一个不在列表里的词，意味着你应该选择更接近的列表内术语
- 句法亮点字段如果没有真实发现，必须留空数组，不要凑数
- 不要做"这首词章法精妙"这类无信息评价
