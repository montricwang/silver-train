# Skills

本目录存放 songci-commentary 项目的 skill 定义。每个子目录是一个独立 skill，包含一份 SKILL.md（描述与指令）。

## 当前 v0.1 skill 清单

- `imagery_analysis/` — 提取与分析意象，建立意象关系网络
- `spatiotemporal_analysis/` — 分析时间序列、空间组织、虚实安排、视角分布
- `composition_analysis/` — 分析整体章法、起调煞拍、铺叙手法、传统术语适用

## 协作关系（v0.1）

三个 skill 在 v0.1 阶段独立运行，互不依赖。
未来 v0.2 计划：composition_analysis 将引用前两者的输出作为分析素材。
