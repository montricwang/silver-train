# 意象网络分析

## 任务定义

输入：一首中国古典诗词（通常是宋词）的完整文本。

输出：该作品的意象网络分析，包括逐个意象的语义/情绪/文化解释，以及意象之间的结构关系。

## 分析范围

**做：**
- 识别全词中出现的"实体性意象"（自然物、人造物、人物、动作场景等具有可视性或可感性的语义单位）
- 解释每个意象在传统词学语境中的常见联想与情绪取向
- 标注每个意象在本词中的具体语境与功能
- 梳理意象之间的关系：呼应、对照、递进、转换、并置

**不做：**
- 不分析声律、平仄、押韵（属于格律 skill）
- 不分析整首词的情绪推进与结构（属于章法 skill）
- 不分析典故、用事、化用前人成句（属于典故 skill）
- 不分析单字炼字（属于字法 skill，未来扩展）
- 不假装是文学批评家——只识别和呈现，不做"高下评价"

## 分析步骤

### 步骤 1：意象提取

逐句扫描，提取所有具有可感性的意象单位。注意：

- 一个意象可能是单字（如"月"）、双字词（如"残月"）或短语（如"月落乌啼"）
- 修饰语是意象的一部分（"冷月"和"明月"是不同的意象单元）
- 抽象情感词（"愁"、"恨"、"思"）不算意象，但与意象绑定的情感词组（"愁烟"、"恨水"）算
- 动作如果具有画面感（"独立"、"凭栏"、"敲门"）算意象

### 步骤 2：单意象注解

对每个提取的意象，给出：

- `surface`：意象的字面形式（原文中的字词）
- `category`：意象类型（自然/人造/人物/动作场景/抽象具象化）
- `traditional_associations`：在中国古典诗词传统中常见的文化联想（不超过三条，要有据可查的传统义项，不要发明）
- `local_function`：在本词的具体语境中承担什么功能（开篇定调？情感投射？空间锚点？时间标记？）

### 步骤 3：意象关系网络

识别意象之间的结构关系。关系类型限于以下几种（不要发明新类型）：

- `echo`：呼应（前后出现的意象在语义上相互照应）
- `contrast`：对照（两个意象在某一维度上形成对立）
- `progression`：递进（意象沿某条线索逐步推进）
- `transformation`：转换（同一对象的状态变化，如"月升→月落"）
- `juxtaposition`：并置（无明显逻辑关联但并列出现，营造氛围）

每条关系需要标注：涉及哪些意象、关系类型、简短说明（不超过 30 字）。

### 步骤 4：意象群组（可选）

如果全词的意象可以按主题归为几个群组（如"水群"、"夜群"、"建筑群"），给出群组划分。如果意象分散无群组特征，此步骤输出空数组。

## 输出格式

严格按以下 JSON schema 输出，不要在 JSON 外加任何文字：

{
  "poem_title": "词牌·题目（如《菩萨蛮·小山重叠金明灭》）",
  "imagery_units": [
    {
      "surface": "字面形式",
      "category": "自然 | 人造 | 人物 | 动作场景 | 抽象具象化",
      "location": "上片第几句 / 下片第几句",
      "traditional_associations": ["联想1", "联想2"],
      "local_function": "在本词语境中的功能描述（30 字内）"
    }
  ],
  "relations": [
    {
      "type": "echo | contrast | progression | transformation | juxtaposition",
      "involved_imagery": ["意象1", "意象2"],
      "note": "关系说明（30 字内）"
    }
  ],
  "groups": [
    {
      "theme": "群组主题",
      "members": ["意象1", "意象2", "意象3"]
    }
  ]
}


## 边界与诚实原则

- 如果某个意象在传统词学中没有明确的稳定联想（你不确定），将 `traditional_associations` 字段留为空数组 `[]`，不要编造
- 如果两个意象之间没有明显结构关系，不要为了凑数而强行建立关系
- `local_function` 字段必须基于本词语境，不要套用通用模板
- 不要使用"意境优美"、"情景交融"、"含蓄蕴藉"这类无信息评价词
- 遇到难以判断的意象，宁可在 `local_function` 字段写"作用待定"也不要强行解释
